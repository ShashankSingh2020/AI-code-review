# AI Code Review + Repository Analyst

An automated code review pipeline built with FastAPI, SQLAlchemy 2.0 (asyncpg), Neon Cloud PostgreSQL, and Python static analysis engines (Ruff, Radon AST analysis), integrated with an evidence-grounded AI review synthesis layer.

## Architecture & Features
- **Shallow Clone Ingestion**: Safe, sandboxed Git cloning enforcing branch, timeout, and storage size limits.
- **Deterministic Static Analysis**: Automated lint, runtime hazard, and security checks via Ruff.
- **AST & Cyclomatic Complexity**: Native Python AST parsing for dangerous constructs (`eval`, bare `except`) and Radon complexity scoring.
- **Dependency Graph Mapping**: Traversal of import relations across modules to build an architectural dependency map.
- **AI Synthesis**: Executive code health reviews generated by Google Gemini (with offline fallback).

## Tech Stack
- **Backend**: FastAPI, Uvicorn, Pydantic v2
- **Database**: PostgreSQL (Neon Cloud) via SQLAlchemy 2.0 & asyncpg
- **Analyzers**: Ruff, Radon, Python AST
- **AI**: Google GenAI SDK (Gemini 1.5 Flash) / Mock Provider
